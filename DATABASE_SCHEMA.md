# Database Schema Diagram

## Overview
This document describes the database schema for the wealth management application, ensuring clarity and readability.

## Diagram

- **User** (background: #ffffff; text: #000000)
- **Account** (background: #f0f0f0; text: #333333)
- **Transaction** (background: #e0e0e0; text: #222222)
- **Investment** (background: #ffffff; text: #000000)
- **Portfolio** (background: #f9f9f9; text: #444444)

## Relationships
- Users can have multiple Accounts.
- Accounts can have multiple Transactions.
- Transactions can be linked to multiple Investments.
- Portfolios can contain multiple Investments.
